# 视频会议网页版

一个最小可用的视频会议 Web 应用：

- 创建会议并生成可分享链接
- 通过链接加入同一个会议室
- 浏览器端实时音视频通话
- 参会者列表和简单文字消息
- 麦克风、摄像头开关
- 会议中共享屏幕，并可停止后切回摄像头
- 协作白板，支持手写、荧光笔、文字、橡皮和清空

## 启动

```bash
npm install
npm start
```

打开 `http://localhost:3000` 创建会议。

## 说明

本项目使用 WebRTC 做点对点音视频，使用 WebSocket 做信令交换。当前配置了公开 STUN 服务，适合本地、局域网或部分公网网络测试。生产环境要稳定穿透复杂 NAT，需要配置 TURN 服务，并建议使用 HTTPS 部署。

屏幕共享依赖浏览器的 `getDisplayMedia` API，需要用户点击“共享屏幕”按钮后手动选择要共享的窗口、标签页或屏幕。

白板内容通过 WebSocket 实时同步。同一个会议内中途加入的用户会收到当前会议的白板历史；当最后一个用户离开会议后，服务器会清理该会议的白板内容。
