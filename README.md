# 云会议 · AI 视频会议

浏览器打开即用的视频会议，参考 Zoom / Google Meet 的核心体验，并内置 Claude 驱动的 AI 助手：**实时字幕与翻译、AI 笔记、一键会议纪要、会议问答**。

## 功能

### AI 助手
| 功能 | 说明 |
| --- | --- |
| 实时转写 | 任何人点「字幕」或「开始转写」即为全场开启；每个人的发言带姓名、时间戳实时变成文字 |
| 字幕 + 同声翻译 | 每位参会者可以选择自己想看的语言（12 种），字幕和转写自动翻译；同一句话全场只翻译一次 |
| AI 实时笔记 | 摘要、要点、决议、待办（自动识别负责人和截止时间）、待解决问题；转写期间约每 90 秒自动更新，全场共享 |
| 会议纪要 | 一键生成正式纪要（摘要 / 议题讨论 / 决议 / 待办表 / 下一步），流式输出，可复制或下载 Markdown |
| 问 AI | “我错过了什么？”“做了哪些决定？”——基于整场会议内容回答，并标注发言时间 |
| 聊天翻译 | 外语聊天消息一键翻译 |
| 会后摘要 | 离开会议后显示 AI 摘要和待办，可下载纪要和转写 |

### 会议体验
- 入会前预览：摄像头预览、麦克风电平、设备选择、入会前开关音视频
- 宫格 / 主讲人视图自动切换（有人共享屏幕或说话时），双击画面固定，单个画面全屏
- 说话人高亮、静音时说话提醒、按住空格临时发言
- 举手（按举手顺序排列）、表情回应
- 屏幕共享（文字清晰度优先）、协作白板（撤销、导出 PNG、颜色）
- 本地录制：按当前画面布局合成，混合所有人的声音，保存为 webm，全场显示“录制中”
- 主持人控制：全部静音、单独静音 / 关摄像头 / 放下手 / 移出、转让主持人、锁定会议、为所有人结束会议
- 聊天：未读提醒、链接识别、中途加入可看到历史
- 网络质量提示、断线自动重连、按人数自动调整码率（网状 P2P 更省带宽）
- 设置：麦克风 / 摄像头 / 扬声器切换、降噪、镜像、识别语言、翻译语言、AI 输出语言
- 快捷键：`Ctrl/⌘+D` 麦克风、`Ctrl/⌘+E` 摄像头、`Alt+Y` 举手、`Alt+C` 字幕、`Alt+H` 聊天、`Alt+A` AI、`Alt+W` 白板、`?` 查看全部
- 浅色 / 深色自适应，手机布局（底部面板）

## 启动

需要 Node.js 22 及以上。

```bash
npm install
cp .env.example .env   # 填入 ANTHROPIC_API_KEY
npm start
```

打开 `http://localhost:3000`。不配置 API Key 也能正常开会、转写和看字幕，只是 AI 笔记 / 翻译 / 纪要 / 问答不可用。

### 配置项（`.env`）

| 变量 | 说明 |
| --- | --- |
| `ANTHROPIC_API_KEY` | Claude API Key，AI 功能必填 |
| `AI_MODEL` | 笔记、纪要、问答使用的模型，默认 `claude-opus-5-5` |
| `AI_FAST_MODEL` | 字幕翻译使用的模型，默认同 `AI_MODEL`；想要更低延迟和成本可设为 `claude-haiku-5-5` |
| `TURN_URL` / `TURN_USERNAME` / `TURN_CREDENTIAL` | TURN 服务器，跨公司网络、4G 等复杂网络建议配置 |
| `PORT` | 端口，默认 3000 |

## 架构

```
浏览器（每位参会者）                                服务器（Node + Express + ws）
├─ WebRTC 网状 P2P 音视频（perfect negotiation）     ├─ WebSocket 信令、房间状态、主持人权限
├─ Web Speech API 识别「自己的」麦克风 ─ 字幕 ──▶   ├─ 转写 / 聊天 / 白板历史（最后一人离开后保留 15 分钟）
└─ AI 面板 ◀── 翻译 / 笔记 / 纪要 / 问答 ────────   └─ Claude API（server/ai.js，Key 不下发到浏览器）
```

- 每个人只识别自己的声音，所以转写天然带发言人姓名，也不需要把音频上传到服务器。
- 语音识别使用浏览器自带的 Web Speech API，**Chrome 和 Edge 支持**；Firefox / Safari 用户能看到别人的字幕，但自己的发言不会被转写。
- 翻译按「片段 × 目标语言」在服务器缓存，多人选同一种语言时只调用一次。
- 笔记和问答对整段转写使用提示词缓存，长会议反复更新时成本更低。

```
server.js            HTTP / WebSocket / AI 接口
server/ai.js         Claude 调用：translateBatch / generateNotes / streamMinutes / streamAnswer
public/app.js        入会、WebRTC、画面布局、参会者、聊天、控制栏、设置
public/modules/      ai.js（转写/字幕/AI 面板）、whiteboard.js、recorder.js、audio-level.js、ui.js、icons.js
```

## 部署说明

- 摄像头、麦克风、屏幕共享和语音识别都要求 **HTTPS**（`localhost` 除外）。
- 网状 P2P 适合 2–8 人的会议；更大规模需要引入 SFU（如 mediasoup / LiveKit）。
- 开启转写时，参会者的发言文字会发送给服务器和 Claude API 处理；界面顶部会显示“AI 正在记录”提示所有人。
